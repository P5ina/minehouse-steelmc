Module anvil_import 

Source
Expand description

Import of vanilla Anvil worlds into Steel’s region format.

The importer reads a world saved by vanilla Minecraft of the same version Steel targets (steel_utils::version::DATA_VERSION) and writes Steel .srg region files. Steel has no DataFixer, so worlds from older versions must be upgraded by vanilla first (java -jar server.jar --forceUpgrade).

What is converted per dimension:

  • region/: block states, biomes, heightmaps, light, block entities, scheduled block and fluid ticks, postprocessing marks and structure references of minecraft:full chunks.
  • entities/: entities with their passengers.
  • poi/: free tickets of points of interest.

Chunks that are not minecraft:full are skipped; Steel generates them again from the seed. Structure starts are converted when Steel can represent every piece of them; the others are dropped and counted in the report. Jigsaw and template-backed structures are converted so far.

Content Steel does not know (blocks, biomes, block entities or entities from mods) cannot be represented in Steel’s typed format. Unknown blocks become air, unknown biomes become minecraft:plains, and unknown block entities and entities are dropped. Every replacement is counted by id in the ImportReport, so an import can be checked before it is used.
