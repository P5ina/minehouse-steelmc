Template-backed structure pieces: vanilla TemplateStructurePiece subclasses.

Each family is a port of its vanilla load constructor (XPiece(..., CompoundTag)), which rebuilds the StructurePlaceSettings from family constants and a few saved fields. The constants match the ones Steel’s generator uses for the same family.
