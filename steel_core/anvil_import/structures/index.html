steel_core::anvil_import

Module structures 

Source
Expand description

Conversion of vanilla structure starts (StructureStart.createTag) into Steel’s PersistentStructureStart.

A start is converted only when every one of its pieces is. A start with a piece Steel cannot represent, or with data that does not parse, is dropped whole and counted by structure id: a start with missing pieces would generate a different structure than vanilla did.
