Expand description

Level state that vanilla spawn predicates read through ServerLevelAccessor.

Provided Methods§

Source

fn is_block_within_world_border(&self, pos: BlockPos) -> bool

Vanilla getWorldBorder().isWithinBounds(pos).

Level surfaces without a border, such as test levels, accept every block.

Source

fn has_nearby_player( &self, position: DVec3, max_distance: f64, exclude_creative: bool, ) -> bool

Vanilla EntityGetter.getNearestPlayer(x, y, z, distance, filterOutCreative) != null.

Level surfaces without players, such as vanilla WorldGenRegion, never have one nearby.

Source

fn is_unobstructed_by_entities(&self, entity: &dyn Entity) -> bool

Vanilla EntityGetter.isUnobstructed(Entity): no other live entity that blocks building overlaps entity’s bounding box.

Level surfaces without entities, such as vanilla WorldGenRegion whose getEntities is always empty, report every box as unobstructed.

Source

fn biome(&self, pos: BlockPos) -> Option<BiomeRef>

Vanilla LevelReader.getBiome(pos), for spawn predicates that read the biome.

Level surfaces without biome access report None, and callers fall back to their biome-independent rule.

Source

fn surface_slime_spawn_chance(&self, pos: BlockPos) -> f32

The minecraft:gameplay/surface_slime_spawn_chance environment attribute at pos. Level surfaces without environment attributes report its vanilla default, 0.

Source

fn world_gen_seed(&self) -> Option<i64>

Vanilla WorldGenLevel.getSeed, when this level is a WorldGenLevel (a server level or a worldgen region). Other level surfaces report none.
