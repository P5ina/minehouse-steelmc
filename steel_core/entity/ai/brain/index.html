Module brain 

Source
Expand description

Vanilla Brain: memory-driven AI used by mobs such as goats, frogs, villagers and piglins instead of goal selectors.

Memories live behind their own lock so sensors and behaviors can read and write them while the brain ticks its behavior list.

Not yet ported: schedules (Brain.setSchedule and updateActivityFromSchedule), which villagers need.
